AlthermaInterface

Browser-based first flash for a new ESP32.

This browser cannot talk to serial devices. Use Chrome or Edge on a desktop — Firefox and Safari do not implement Web Serial. Serial access was denied. Reload and allow the permission prompt.

Plug the ESP32 into whichever computer has the USB cable, open this page in Chrome or Edge, and click the button. Nothing needs installing — no ESP-IDF, no esptool, no Python.

What it writes

The bootloader, partition table, initial OTA data and the application, at their proper offsets for the ESP32 — the same four images idf.py flash would write. The firmware served here is rebuilt from master automatically, so it is always current.

This is for the first flash only

After this, the device has its own web UI with an OTA tab. Every later update goes over the network — upload a .bin, or have the device fetch a release from GitHub itself. You should not need a cable again.

Then what

  1. The device comes up as an open access point named AlthermaInterface at 192.168.4.1.
  2. Connect to it, open that address, go to Config, scan for your WiFi and save. The device reboots onto your network.
  3. Set the MQTT broker in Config, and check the Debug tab for X10A link health.

Wire the X10A connector with the heat pump powered down, and check the pin mapping in the README first — the data lines cross, and the 8-pin ROTEX variant orders them differently from the 5-pin one.
